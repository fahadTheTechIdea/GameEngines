# Framework city demonstration

This directory is reserved for the framework's complete city demonstration.
It is an example workspace, not a separately commissioned game. No game name,
owner-confirmed art profile or artwork approval is inferred from this folder.

The reusable framework owns catalog expansion, complete nested inventories,
spatial generation and the metadata-to-art handoff. A configured consumer supplies
its visual scopes and canonical GameArts profile when artwork execution begins.
The requested demonstration remains building references → district mockups →
whole-city mockup → reconciled map → production sprites/tiles → native Godot
TileMapLayers. The current implementation and remaining gates are tracked in
[the master roadmap](../../docs/ROADMAP.md).

Technical handoff fixtures live under `generated/art-handoff-qualification` and
are explicitly bounded test programs. They do not represent the completed city.
