# One-way regional world

This framework fixture generates six game-authored regional compound programs
with a staged, directed graph. All six destinations are reachable from the
start through the mandatory pass; the seven physical links only travel forward.
Each region keeps its complete nested source content.

`changed-request.json` changes the topology seed while retaining local programs.
`source-edit.json` is an example edit bound to the exact generation identities
of the verification run; create a fresh edit receipt for another build/session.
This example generates an acyclic topology. No production art or Godot is needed.
