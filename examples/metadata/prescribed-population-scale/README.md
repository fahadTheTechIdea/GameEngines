# Complete prescribed population at larger counts

Framework inputs for the C# metadata engine. Both terrain variants preserve the
complete six-compound source world and add 194 required environmental members:
96 lowland, 96 highland and two woodland features. Counts, source footprints,
clearances and the one-meter separation rule remain authoritative.

The root explicitly selects `Execution: Prescribed`. The contour owner generates
all required anchors from field levels and intent. The placement owner qualifies
the complete 200-member root assignment, with one exact candidate per demand;
fourteen nested programs retain the remaining source content. No missing item
is moved into an empty location or omitted.

Each output contains 223 nodes, 222 physical members, thirteen connected contour
paths and nineteen bidirectional source connections. Raising the terrain by
0.2 meters moves all 194 environmental members. Every source compound, catalog
footprint and source path remains exact within its generated source world.
The schematic consumes the saved field paths and physical geometry directly.

Use WorldCreator.Cli `generate-metadata <recipe.json> <catalog.json> <new-output-dir>`.
Current qualified packets are under `generated/prescribed-population-scale-accepted`.
The test writer `--write-prescribed-population-examples` reproduces the inputs
into a new directory.

Standalone prescribed geometry is qualified at 256 slots; reusable nested programs
at 32 members; a separate 307-member storage program proves that more than 256
new reservation shapes can preserve source passages and still reject one
reservation-only obstruction. These fixtures are not a general throughput claim.
The independent 256 route-exclusion and 1,024 access-site bounds remain.

Regional intent, field levels and counts remain authored. Full area distributions,
automatic world intent, larger solid-obstacle backends and streaming remain open.
