# Mixed-purpose physical programs

Framework qualification inputs, not a commissioned game or a finished world.
The C# engine grows twelve complete camp, workshop and research compounds from
one arrival anchor, a generated branched/looped graph and five reusable nested
programs. All 57 declared objects remain: 56 physical members, including eight
production machines and twelve supply caches. Thirty-seven bidirectional
connections serve all 36 declared travel destinations.

`inland`, `inlet` and `opposite-slope` retain the same catalog and logical intent;
terrain changes the physical result. No object is scattered, shrunk or omitted.
The JavaScript schematic consumes exact C# output geometry.

The example explicitly selects `FirstFeasible` routes, 1,024 route candidates,
100 million work units per regional direction and 10 million per local direction.
Every direction shares the unchanged 200-million actual-work ceiling. Earlier
10-million and 20-million regional attempts exhausted their per-leg budgets;
the original 10-million input is preserved in
`generated/mixed-scale-initial10m`. Increasing an independent ceiling does not
increase the aggregate allowance or certify efficient scaling.

Evidence: `docs/evidence/2026-10-28-mixed-scale-verification.json`.
The wider diversity, terrain composition, interiors and core-world acceptance
gates remain open. Godot is deferred. Browser/design acceptance is not claimed.
