# Stable catalog variation

The normal metadata pipeline expands eleven physical members and eight required
nested components, plus their root. The source phase preserves seven physical
members and four components. Explicit variation rules choose square/wide/tall
markers and badge alternatives; each form retains its source dimensions and
required nested program. Positions and protected spaces are independent of those
choices. This is a qualification fixture, not a complete city.

Use `recipe.json` with `catalog.json` for the baseline. `changed-seed.json` is an
alternative **catalog** changing only the detail-marker rule's seed. Base members
and every position remain fixed. `oversized.json` is a negative catalog: a selected
60×60 form cannot fit, so generation must fail without publishing output or choosing
a smaller alternative. Each run uses the normal `generate-metadata` command and a
new output directory.

Select a member in the schematic to inspect its selected form, allowed alternatives,
seed and source. The Labels toggle can hide overlapping labels without changing
geometry. The nested component can be selected through the contained-items control.
