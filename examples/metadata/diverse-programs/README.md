# Diverse terrain-driven world program

These inland and coastal inputs exercise the shared engine, with no game setup,
mockup, sprites or Godot. The engine derives the terrain region, activity spaces,
source-sized assembly placement, nested contents, approaches, paths and
density-funded landscape. World positions are not an authored object list.

The seven assembly trees differ in constituents and geometry:

| Assembly | Structures | Ground areas | Equipment |
| --- | ---: | ---: | ---: |
| Workshop | 2 | 1 | 3 |
| Depot | 3 | 1 | 4 |
| Habitat | 3 | 1 | 1 |
| Commons | 1 | 2 | 0 |
| Field lab | 1 | 2 | 2 |
| Outpost | 2 | 1 | 2 |
| Lookout | 1 | 1 | 1 |

Each declared program retains its parent, exact source footprints, reservations
and entrances. Reusable nested programs derive local positions from typed
connections and declared directions. Macro allocations use required area intent;
source-footprint anchors replace an unsuitable centroid where needed. This
changes neither source size nor the 25,000 m² region minimum.

Both current inputs produce 61 nodes and 60 physical members: seven compounds,
13 structures, nine ground areas, 13 equipment objects and 18 landscape members.
All 51 bidirectional local links and six bidirectional regional links retain 114
directed, full-width journeys. Landscape count is the complete floor of measured
support mass divided by 250, bounded by the declared catalog minimum and limit.
The engine preserves the accepted source world through the population phase.

This is a bounded framework reference, not a default world/game layout or owner
design approval. It does not qualify arbitrary genres, larger source programs,
volumetric worlds, production artwork or native runtime. An earlier audit found
the larger terrain-demand reference could not place both research sites. That
historical failure remains in its original evidence. The current full regression
now retains all 248/270 nodes, 247/269 physical members and nineteen source
connections under its original inputs and limits; see the
[current execution receipt](../../../docs/evidence/2026-10-30-population-scale-verification.json).
This does not turn the reference into full world-design acceptance.
