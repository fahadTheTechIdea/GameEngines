These framework inputs use the same six complete compounds as the area-population
reference. The engine generates the source terrain, regions, habitat allocations,
compounds and nineteen connections first. Three demand rules measure those actual
habitats and derive whole catalog-member counts before content expansion.

| Habitat | Amount per member | Baseline count | Density × 1.1 count | Catalog minimum |
| --- | ---: | ---: | ---: | ---: |

Amount is density-weighted area in the source field's units times squared surface
units. It is authored game intent, not a real ecosystem population estimate.
Uniform density can instead derive counts directly from area. Counts use floor;
near-integer numerical ambiguity, insufficient minima and exceeded limits refuse
generation. The engine never clamps a count or shrinks a source footprint.

The current totals are 248 nodes/247 physical members for baseline and 270
nodes/269 physical members for richer density. All nineteen bidirectional source
paths survive. Area strata supply purposeful coordinates and do not mean complete
physical land coverage or acceptance of a whole game.
