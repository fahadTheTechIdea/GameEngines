# Interior-anchor framework inputs

These are reusable framework fixtures, not a particular game or an art profile.
`uniform` and `weighted` retain seven metadata nodes, two exact physical sites,
four logical constituents and a bidirectional physical interface route. Allocation
anchors use explicit bounded interior clearance. The weighted program additionally
chooses interior representatives for its generated spaces, keeping true mass
centroids as separate evidence. Source sites remain 84m² with 192m² reservations;
logical constituents do not acquire invented physical geometry.

`steep-source` is the complete seven-compound source phase on a 1.8-meter generated
ridge: 43 nodes, 42 physical members, fourteen structures, seven yards, fourteen caches
and 82 directed paths. Suitable area is 25,650m² under the original 25,000m² minimum
and 0.1 grade rule. The 20th declared 30-degree layout setting succeeds; nineteen
rejections remain visible. All source sizes/counts and work bounds stay intact.
This fixture deliberately declares the source scope: the full follow-on landscape
population remains unresolved because some mass-balanced strata are disconnected.
It is not a full-world or expressive-range completion claim.

The existing `generate-metadata` CLI accepts each recipe/catalog and a new output
directory. Current checked packets are `generated/interior-anchors-verified/*`.
The test writer also saves `generated/interior-anchor-current-inputs/holed-area-plan.json`
as an API geometry oracle, not a full-world packet. Its 104m² support has true mass
centroid (6,5) in a protected hole; the representative stays on valid support with
clearance within 0.01 of the analytic optimum `7 - sqrt(24)`.

[Evidence](../../../docs/evidence/2026-10-29-interior-anchors-verification.json)
records source identities, exact checks, failure history and remaining gates.
Godot, artwork/runtime, browser interactions and owner world-design acceptance
remain deferred/unqualified.
