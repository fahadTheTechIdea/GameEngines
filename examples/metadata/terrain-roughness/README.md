# Seeded terrain roughness

These framework inputs contain the same two required compounds and three
bidirectional routes. The baseline uses the terrain-detail defaults. The other
recipe changes only persistence and lacunarity, retaining the protected corridor,
source dimensions and required paths. Its small detail amplitude keeps this
fixture focused on integration; it is not a visual landscape quality example.

`Persistence` scales successive octave amplitudes; `Lacunarity` scales their
frequency. See the [terrain contract](../../../docs/WORLD_METADATA.md).
