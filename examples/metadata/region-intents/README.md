# Terrain-derived region intent fixtures

Framework fixtures, not configured games. `west-pond` and `east-pond` use the same
catalog and required program capacities. Only the terrain pond changes. Each
recipe has no authored regional seeds and no root placement anchor coordinates;
the C# region owner selects a connected suitable habitat and computes its interior
anchor. A declared region-anchor binding starts the complete connected program.

Both qualified packets retain 17 nodes, 16 physical members and 11 routes, with
source-sized nested constituents. Local program grammars and the world's coordinate
origin remain authored. These fixtures do not establish autonomous world intent,
broad genre/design coverage or visual acceptance. Godot stays deferred.

The actual CLI publication, file/session/checkpoint replay, independent geometry/
assignment checks and Node witness checks are recorded in
[the evidence record](../../../docs/evidence/2026-10-29-region-intent-verification.json).
One concurrent regression publication failed with atomic-move access-denied;
the isolated serial rerun passed, with no failed output published. Its sharing
cause remains unconfirmed.
