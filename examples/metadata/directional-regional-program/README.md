# Directional terrain in a regional world

These two framework inputs differ only in seeded terrain orientation. The
engine generates six complete regional programs within an irregular outer
boundary, preserving 30 nodes, 18 source-sized physical members and seven
bidirectional regional journeys. The example uses small-amplitude terrain;
in the verified run one forward route changed shape and all seven changed cost.
The exact region anchors remained unchanged.

The regions are game-authored programs and do not imply streets or a particular
genre. This example is not a complete game, visual approval or Godot project.
