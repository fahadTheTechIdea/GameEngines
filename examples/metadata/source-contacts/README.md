# Source-sized terrain-contact placement

This framework example is the complete source phase of the larger terrain-demand
reference. It retains six compounds, their complete nested catalog trees, 29
nodes, 28 physical members and nineteen bidirectional routes. Both required
research compounds fit the forest with their source dimensions unchanged.

`source/recipe.json` and `source/catalog.json` use the normal `generate-metadata`
pipeline. No game setup, artwork or Godot project is required. The shared engine
uses semantic boundary/source-vertex contacts; the example does not supply
per-object replacement positions or a genre-specific generator.

The same exact source/catalog inputs pass both typed file generation and the
actual CLI. Five analytic cases cover reservations, a rotated frame and both
coordinate limits. Impossible packing, exact work, candidate exhaustion,
cancellation and replay checks remain explicit.

The later 219-member population now passes with coordinated source commitment.
The source remains provisional until required downstream spacing is qualified;
accepted source members then stay exact. Counts, source dimensions, prescribed
population centroids, one-meter clearance and budgets are retained.
