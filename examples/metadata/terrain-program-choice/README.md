# Terrain-exact capacity-aware program choice

The terrain determines exactly four members in the dry habitat and three in the
reduced habitat. Both must provide 15 units. The authored program-mix rule selects
complete catalog forms under its explicit source, cost and count limits: the dry
world uses two 3-unit and two 5-unit forms; the reduced world uses three 5-unit
forms. All source footprints remain intact and no extra member is added.

This is an explicitly selected solver policy. Seeded `Variation` is a different
policy and is not silently replaced. An impossible demand or budget is rejected.
Use `generate-metadata` with either recipe and the shared catalog, then
`verify-metadata` for source replay. This framework example is not a game or art.
