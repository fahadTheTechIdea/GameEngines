# Mixed local programs

This example uses the existing terrain-region recipe and the normal metadata API/CLI. Four ordered programs use an oriented grid in the western region; three programs use a power-diagram partition in the eastern region. Both clip against the actual region geometry. The protected hole and diagonal excluded channel remain outside the allocations.

Every program has a protected anchor, minimum area, purpose and source rule. Seven catalog sites retain their 8×6-meter physical shapes and 10×8-meter reservations; fourteen constituent metadata points are retained. Two required interfaces select continuous shared boundary spans. Those spans are geometry obligations, not qualified roads, entrances or bridges.

The 5,793.24 square meters of suitable land are assigned to program areas with zero residual. This does **not** mean the whole area is populated: the seven site footprints total only 336 square meters (560 square meters including reservations). Further grounds/content and physical constituent geometry remain to generate. Local layouts can explicitly retain residual land when its purpose is supplied; the engine does not fill it with arbitrary objects.

This is a mixed-layout qualification packet, not a completed city or production map. Bounded repartition after content/access failure, physical interface traversal, full content coverage, GameArts mockups/production assets and native Godot acceptance remain open.
