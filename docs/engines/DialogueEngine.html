Purpose

DialogueEngine runs an authored conversation graph and keeps the session state: variables, quest progress, visit counts, the call/interrupt stack, the waiting queue and a bounded history. Text is never stored in the document — every line, option and quest title is a localisation key with typed arguments, so one document serves every language.

It owns

Graph validation, execution, choices, random and variant selection, calls, priority and queueing, quests, content warnings, history, save and hot reload.

It does not own

Rendering, portraits and audio assets, the speaker roster (an ISpeakerCatalog answers), timers (the host calls Timeout), or the localised strings.

Deterministic

Random choices are seeded rolls keyed by conversation, node and roll counter. The same session and seed replay identically.

Document format

{ "format": 3, "id": "harbour.dialogue",
  "variables": [ { "id": "trust", "type": "int", "initial": 0, "min": 0, "max": 10 } ],
  "externalFacts": [ { "id": "met_guard", "type": "bool" } ],
  "speakers": [ { "id": "mara", "portraits": ["calm"], "emotions": ["warm", "angry"] } ],
  "quests": [ { "id": "hold", "titleKey": "quest.hold.title",
                "startStage": "order",
                "stages": [ { "id": "order", "journalKey": "quest.hold.order", "advance": [] } ] } ],
  "conversations": [ { "id": "main", "start": "hi", "priority": 0, "onBusy": "queue", "interruptible": true,
    "nodes": [ { "id": "hi", "kind": "line", "speaker": "mara", "portrait": "calm",
                 "key": "main.hi", "args": { "name": "ext.player_name" }, "next": "ask" } ] } ],
  "historyLimit": 100,
  "contentWarnings": [ { "tag": "violence", "fact": "comfort_violence", "action": "skip" } ] }

Strict JSON: unknown/missing fields, duplicate ids, unknown speakers/portraits, unreachable nodes, loops without a wait, call cycles and silent chains are refused (DLG_*). The document stores a SHA-256 digest of its exact text; a save names it.

Nodes

KindBehaviour
lineSpeaker, portrait, key, typed args, optional tags/voice/emotion/auto-advance, glue, content-warning alternative. Waits for Next unless a skip warning passes it.
choiceOptions with a guard, showWhenUnavailable, weight, effects, tags and next. A seeded choice picks among available weighted options; a timeout names the option the host should take.
branchOrdered cases of guard + next, with an otherwise target.
randomWeighted outcomes; the roll is (seed, conversation, node, counter).
effectsApplies effects in order, then goes to next.
call / returnRuns another conversation as a subroutine and returns a result; call cycles are refused.
variantOffers an option list by mode and an exhausted target when none remain (seen-once or shuffle-once text).
endEnds the conversation with a result string.

Guard is the shared condition grammar over document variables and ext.* facts. Effects and conditions record which facts they need, which the loader uses for checks.

Effects

EffectMeaning
setSet a variable to a literal or fact value.
addAdd to a numeric variable, clamped to its range.
startQuest, setStage, finishQuestMove a quest to its start, a stage or a terminal status.
signalRaise a named signal with literal or variable arguments for the game layer.

Runtime API

var set     = DialogueLoader.Load(json, speakerCatalog);   // format 3; catalog answers who may speak
var runtime = new DialogueRuntime(set, seed);
var facts   = new Dictionary<string, FactValue> { ["met_guard"] = FactValue.From(true) };

DialogueStep step = runtime.Start("main", facts);
// step.Kind: Line | Choices | Ended | Queued
step = runtime.Next(facts);           // after a line
step = runtime.Choose("option-id", facts);
step = runtime.Timeout(facts);        // host clock decided the choice timed out
var why = runtime.ExplainChoice(facts);  // Availability + reason per option
runtime.Interrupt("alarm", facts);    // preempt if allowed by priority/interruptible
  • Starting a conversation while one is open follows onBusy: refuse (DLG_BUSY), queue, or preempt by priority.
  • Unavailable options are hidden or shown disabled; choosing one is refused (DLG_OPTION_UNAVAILABLE).
  • A step limit and call-depth limit prevent an unbounded graph (DLG_STEP_LIMIT, DLG_CALL_DEPTH).
  • Every step carries the events raised on the way (VariableEvent, QuestEvent, SignalEvent, ConversationEvent, SkippedEvent).

Quests and stages

QuestDef has an id, title key, start stage and ordered stages. Each StageDef has a journal key, a list of StageRule (guard → next stage) and an optional terminal ends status. StartQuest and UpdateQuests(external) return the events raised; statuses are NotStarted, Active, Completed, Failed, Abandoned. A quest that cannot advance and loops is refused (DLG_QUEST_LOOP).

Content warnings

contentWarnings maps a tag to an external fact and an action. When a tagged line is reached and the fact is true, skip passes the line without showing it (it does not wait), and replace shows the node's declared alternative key instead. Warnings must be declared by the tag the node uses (DLG_CW_UNDECLARED), must name an external fact (DLG_CW_FACT), and a replacing warning needs an alternative (DLG_CW_ALTERNATIVE).

Localisation and translation

  • DialogueSet.Keys lists every key and its placeholder names; KeyUses says where each is used.
  • TranslationSheet exports and imports a translator sheet, validating placeholders and rejecting stale or unknown keys (SheetImport).
  • LocaleCoverage reports missing, extra and malformed entries per table.
  • Plural forms follow CLDR categories; the locale table decides the form.

Save, history and reload

  • DialogueSave.Write(runtime) / DialogueSave.Open(set, bytes); StateDigest(state) and Canonical(state) for journals.
  • A save verifies the document digest (DLG_SAVE_DOCUMENT) and its own state digest (DLG_SAVE_STATE).
  • HistoryLog keeps up to historyLimit shown lines and taken answers (line/answer, speaker, key, args, chosen option, seen, skipped, replaced).
  • Reload(next, mode, map) hot-swaps a document. ReloadMap follows renamed variables, quests and nodes; an incompatible reload is refused (DLG_RELOAD_INCOMPATIBLE) unless the mode explicitly allows dropping state.

Importers

YarnImporter and InkImporter convert scripts into a dialogue document plus a locale table and report. ImportCapabilities gives the capability matrix: each feature is Converted, Approximated, Dropped or Refused with a sample — never silently lost. Yarn random functions and Ink scoping, threads and shuffle-once/stopping are covered.

Exit codes: 0 done (coverage complete), 1 refused or incomplete, 2 usage or file problem.

GameRuntime integration
