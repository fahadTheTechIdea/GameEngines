Purpose

RelationshipEngine simulates how people feel about each other. It owns needs and mood, opinions on named axes, the memories that formed them, the bonds and social ranks between actors, and the attempts to interact. It does not decide what an interaction looks like, move anyone, or render a face — it reports changes and answers queries.

It owns

Needs, decay, mood derivation, moodlets, memories, axes, ladders, bonds, gift taste, interactions, gossip, communities, standing, balance.

It does not own

Dialogue text, animation, pathfinding, factions or diplomacy, or the game's schedule — activities come from the calendar host.

Deterministic

Every random decision is a seeded roll; a save is a complete copy of state and a scenario replays identically.

Document format 3

Strict format 3 (older versions are refused with REL_FORMAT_2 / REL_FORMAT_OLD). Sections: seed, time.stepsPerDay, limits, facts, axes, needs, sources, mood, moodlets, memories, traits, ladders, bonds, gifts, tastes, gossip, social, interactions.

Limits bound actors, edges per actor, memories per edge and moodlets per actor; everything is refused when it cannot run, with REL_* codes.

Needs, sources and activities

{ "id": "hunger", "max": 1000, "initial": 800, "decayPerDay": 900, "critical": 200, "rearm": 350,
  "urgency": [ [0, 1000], [200, 800], [600, 200], [1000, 0] ],
  "decayModifiers": [ { "when": { "fact": "cal.season", "op": "eq", "value": "winter" }, "permille": 1300 } ] }
  • A need decays per day, optionally scaled by conditional modifiers. critical raises a once-armed alert until rearm.
  • urgency is a piecewise-linear curve from level to urgency; Urgency(actor, need) answers it.
  • sources map an activity to a need and a refill per day. The host sets the actor's activity (SetActivity), usually from the calendar schedule.
  • A day is spread over social.schedule — Atomic applies it in one step, Spread over the first five steps.

Mood and moodlets

mood = trait base + Σ need weights + Σ active moodlet magnitudes
     (clamped to min/max, resolved to the highest state whose threshold is reached)
  • MoodDef carries range, base, hysteresis, need weights and named states (content, happy, …) with thresholds.
  • A moodlet has magnitude, duration, decay (Fixed, Linear, HalfLife) and stack mode (Refresh, Stack, Replace, Unique).
  • Grant(actor, moodletId, scalePermille, source) adds one; Mood(actor) and MoodStateId(actor) answer.
  • Traits can shift the mood base, need decay and mood scales.

Edges, axes and memories

An edge is one actor's opinion of another: a value on each declared axis (affinity, trust, attraction, …), the memories that formed it, cooldowns and bonds.

{ "id": "was-gifted", "effects": [ { "axis": "affinity", "magnitude": 120 }, { "axis": "trust", "magnitude": 30 } ],
  "duration": 720, "decay": { "kind": "halfLife", "halfLife": 240 },
  "stack": { "mode": "refresh", "max": 1 }, "tags": ["kindness"],
  "spread": { "as": "heard-kindness", "permille": 600, "chance": 700, "hops": 2 } }
  • Remember(holder, subject, memoryId, scalePermille) records a memory; its contribution decays over time.
  • Opinion(from, to, axis) is the baseline plus memory contributions, clamped to the axis range.
  • Axes drift toward baseline per day; AdjustAxis applies an explicit change.
  • Actor traits can scale axes through the trait's axis scales.

Ladders and bonds

  • A LadderDef turns an axis value into a named step with hysteresis; LadderStateId(from, to, ladder) answers.
  • BondDef: symmetric or directional, exclusive, broken when an axis falls below a threshold; SetBond/HasBond.
  • Ties (triads) are balanced or not: Triads(holder, subject) returns TriadReading for each intermediary, with wanted/has and balance.

Interactions and gifts

IReadOnlyList<InteractionOffer> offers = runtime.Offers(actorId, targetId, hostFacts);
InteractionResult r = runtime.Perform(
    new InteractionRequest("compliment", actorId, targetId, witnesses, gift: ""), hostFacts);
// r.Accepted, r.Score, r.Threshold, r.Noise, r.Changes
  • An interaction has tags, a precondition condition, a cooldown, a gift flag, desire rules and effects on the actor's edge, the target's edge, needs, moodlets or bonds.
  • Acceptance is scored from the interaction, the actors' state and the declared modifiers; a seeded roll against a threshold decides, so refusal is possible and explained.
  • Offers reports availability with a reason and a desire value, so a UI can grey out what cannot be done.
  • Gifts use tags and the receiver's tastes: GiftTaste(receiver, gift).
  • Witnesses remember what they saw at a scaled magnitude.

Gossip

A memory can spread: SpreadDef(memory, permille, chance, hops) creates the same memory in others through the social graph. gossip rules set the trust axis, minimum trust, maximum tellings and listeners per memory. Spreading is seeded and bounded.

Derived social state

  • Communities: label propagation over strong positive edges, recomputed on a configured axis; CommunitySize(actor) answers.
  • Standing: iterative trust weighting over the graph; social.standing sets axis, threshold, damping, iterations and the pre-trust trait.
  • Balance: structural balance over triads, limited to top-k actors and a bounded number per actor, with a seeded chance.
  • Schedule: how the day's needs and sources are applied (Atomic or Spread).

Facts

RelationshipFacts declares the fact ids usable in conditions, prefixed by actor., target., edge. and reverse.:

  • Actor: mood, mood_state, activity, community, community_size, standing, need.<id>, trait.<id>.
  • Edge: known, same_community, state.<ladder>, bond.<id>, memory.<id>, and each axis id.
  • reverse.* reads the target's edge back to the actor.

Anything else is a host fact and must be declared. These facts feed dialogue conditions and AI percepts.

Runtime API

var set     = RelationshipLoader.Load(json);        // format 3
var runtime = RelationshipRuntime.Create(set, startStep);
runtime.AddActor("mara", traits, tastes);
runtime.SetActivity("mara", "work");
RelationshipChanges changes = runtime.Advance(toStep, hostFacts);  // daily needs, decay, social refresh
runtime.Grant("mara", "festival-joy", 1000);
runtime.Remember("mara", "jory", "was-gifted", 1000);
var mood    = runtime.Mood("mara");
var opinion = runtime.Opinion("mara", "jory", "affinity");
var state   = runtime.LadderStateId("mara", "jory", ladder);

Advance is monotonic and bounded; Owed(toStep) reports outstanding steps. RelationshipChanges lists typed changes for the game layer.

Exit codes: 0 done, 1 refused or incomplete, 2 usage/scenario/file problem. The multi-seed sweep is the balance tool.

GameRuntime integration

RelationshipComponent queues actor, activity, interaction, grant, memory, need, axis, bond and mood requests, then advances with the session clock and publishes changes.
