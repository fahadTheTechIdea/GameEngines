Purpose

EngineCommon is not a game system; it is the shared foundation the game systems are built on. It exists so that every engine refuses bad input the same way, reads conditions the same way, rolls random numbers the same way, formats localised text the same way, and can be tested with the same guards.

Depend on it

Every engine core references EngineCommon.Core; graph, balance and test support are added only where used.

Depend on nothing

It references no engine. Facts come from ScenarioEngine.Contracts, the shared contract assembly.

One rule, one place

If two engines need the same rule, it belongs here — not copied into both.

Strict documents and refusals

StrictJson is constructed with the engine's own RefusalCodes (format, unknown field, missing field, range, duplicate, reference) so a refusal always carries the right prefix.

var json = new StrictJson(EconomyCodes.ForDocument);
var root = json.Object(element, "market", ["id", "currency", "pairs"], "policies");
long treasury = json.Long(root, "treasury", "market", 0, EconomyFacts.MaxMoney);
var id = json.Id(root, "id", "market");
  • Every field present unless declared optional; no unknown field; duplicate names refused; numbers are whole and range-checked; ids use a fixed alphabet.
  • Nothing is repaired or defaulted. A failure is an EngineRefusedException whose Code names the first rule that failed.
  • Every engine declares its codes in a static class and a RefusalCodes ForDocument.

Conditions

The grammar belongs to ScenarioEngine.Contracts: all, any, not, and { "fact", "op", "value" } with depth and size limits. EngineCommon.Conditions reads it strictly, checks every fact against the engine's declarations and reports the facts it needs.

Condition when = conditions.Read(element, "shock.when", hostFacts);
IReadOnlyList<string> needed = Conditions.FactsOf(when);
bool holds = Conditions.Evaluate(when, values);

ConditionExplanation.Describe renders why a condition held or failed for a trace or an explain command.

Deterministic rolls and digests

ulong value = DeterministicRoll.Next(seed, "economy-price:town:bread", index);
long roll    = DeterministicRoll.Below(seed, stream, index, bound);
int permille = DeterministicRoll.Permille(seed, stream, index);

SplitMix64 over FNV-1a of the stream name: a pure function of seed, stream and index, with no state, so calls may be made in any order and replay identically. Never use Random or wall-clock time in an engine.

Digest.Of(text) / Of(bytes) is upper-case SHA-256 hex — the digest every document and save carries.

Locale, plurals and direction

  • LocaleTable.Load(text) — strict format 1: locale plus messages; a message is text or a form object with select, other and CLDR categories.
  • LocaleRenderer.Render(table, key, args) — substitutes MessageArg values; numbers select a CLDR cardinal/ordinal form, text selects by value. Missing key, missing form and bad placeholders are refused (LocaleCodes).
  • PluralRules.Categories(locale) — supported locales only; the data is Locale/cldr-plurals.json.
  • TextDirection.IsRightToLeft(locale) — for layout and mirrored punctuation.
  • CoverageRules.Report(keys, table, notGiven) — missing keys, unknown keys and placeholders the key does not give; Check refuses at the first problem.
  • LocaleChain — fallback from a specific locale to a base locale.

Graph library

All algorithms run on CsrGraph (compressed sparse row) with a reused GraphScratch, so a large graph is not reallocated per query.

AlgorithmEntry point
BuildGraphBuilder.Create(nodes, out builder); Add, AddUndirected, Build(); bounds in GraphLimits.
Shortest pathsDijkstra.Run(graph, source, target, scratch) → ShortestPaths.PathTo(graph, target); BellmanFord.Run for negative edges.
TraversalBfs.Run(graph, sources, maxDepth, reuse), Components.Run.
OrderTopologicalSort.Run → order or GraphCodes.Cycle.
FlowMinCostFlow.Run(graph, source, sink, maxFlow, maxAugmentations, scratch); Decompose into paths.
DegreesDegrees.Run(graph, reuse) → DegreeTable.Top(measure, k).
CommunitiesLabelPropagation.Run(graph, initialLabels, maxRounds, scratch).
TrustTrustIteration.Run(graph, preTrust, alpha, maxIterations, epsilon, scratch).

Every result has an Explain() and a refusal code; overflow and oversize are refused, never wrapped.

Balance library

  • SeedSweep.Run(options, perSeed) and RunWithEvents — run the same document over many seeds and collect metrics; Render prints the table.
  • SeedDocument.WithSeed(document, seed) — replace the seed of a JSON document for a sweep.
  • FixedEffortSplitting — multi-stage splitting to estimate rare probabilities; DerivedSeed derives independent seeds.
  • AutoEfforts.Plan — allocate a run budget across stages from a pilot.
  • ConditionalEstimator.Run — conditional Monte Carlo with weighted informative outcomes.
  • SplitSummary.Of — mean, standard error, interval, median, min/max, extinct runs.
  • SampleStats — percentiles, means and fixed formatting; IntegerRoot — exact integer roots.

Tail tool

EngineCommon.TailTool reads recorded samples and reports tail shape without a live engine: TailCli, TailSample, PeaksOverThreshold, DipTest, SilvermanTest, ModalityCheck, BoundCheck. It is a measurement tool, not part of a game session.

Test support and guards

EngineCommon.TestSupport/SyntaxGuards provides Roslyn checks used by guard tests: no wall clock, no coalescing that hides a refusal, no duplicated rule text, and repository-wide rules. A guard that reads source is a real test only when it can fail; see docs/ENGINE_ALGORITHM_REVIEW.md for the review standard.
