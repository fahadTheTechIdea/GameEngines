How to read a page

  • Boundary — what the engine owns and what belongs to the game or another engine.
  • Format / content — the strict document or content schema, with a working snippet.
  • API — the public entry points and the important contracts.
  • Determinism and persistence — seeds, digests, save checks, replay.
  • CLI and GameRuntime — authoring tools and the component/event integration.
  • Source map — where to read the code, plus the owned design record.

The matching skills are under skills/gameframework-<engine>/SKILL.md. A skill is a compact operating guide; the HTML page is the fuller reference, and the owned markdown design record remains the design authority.
